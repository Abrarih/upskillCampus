# 🏠 NeuroHome – IoT Smart Home Automation

NeuroHome is an IoT-based Smart Home Automation project built using **Python, MQTT, FastAPI, and a Web Dashboard**.  
It simulates real-time sensor data and allows users to control home devices like lights and fans through a browser.

---

## 🚀 Features
- Real-time temperature and motion monitoring
- MQTT-based device communication
- Web dashboard for device control
- FastAPI backend APIs
- Local Mosquitto MQTT broker
- Device simulator for testing

---

## 🛠️ Technologies Used
- Python
- FastAPI
- MQTT (Mosquitto Broker)
- Paho MQTT Client
- HTML, CSS, JavaScript
- VS Code
